# Awesome Chat

### Ứng dụng nhắn tin thời gian thực đa nền tảng

- Thời gian phát triển: 08/2026 – 09/2026
- Vai trò: Lập trình viên độc lập (Sole Developer)
- Mã nguồn: [github.com/ngochahh2005/mock-chat](https://github.com/ngochahh2005/mock-chat)

### Tổng quan

Awesome Chat là ứng dụng nhắn tin thời gian thực được phát triển bằng
Flutter. Ứng dụng cung cấp các chức năng xác thực người dùng, trò chuyện
1–1, gửi hình ảnh và sticker, tìm kiếm bạn bè, quản lý hồ sơ cá nhân và
nhận thông báo tin nhắn mới.

### Tính năng chính

- Đăng ký và đăng nhập người dùng
- Xác thực tài khoản bằng Firebase Authentication
- Trò chuyện 1–1 theo thời gian thực
- Gửi tin nhắn văn bản
- Gửi hình ảnh và sticker
- Tìm kiếm bạn bè
- Tìm kiếm nội dung tin nhắn
- Quản lý phòng chat
- Hiển thị số lượng tin nhắn chưa đọc
- Quản lý và cập nhật hồ sơ cá nhân
- Cập nhật ảnh đại diện
- Push Notification và Local Notification
- Hỗ trợ tiếng Việt, tiếng Anh và tiếng Nhật
- Giao diện responsive trên nhiều kích thước màn hình

### Kiến trúc dự án

Dự án được tổ chức theo mô hình Feature-first kết hợp Clean Architecture.

Các tầng chính:

- `Presentation`: Giao diện, BLoC và trạng thái màn hình
- `Domain`: Entity và abstract repository
- `Data`: Model, repository implementation và service
- `Common`: Widget, extension, config và tiện ích dùng chung
- `DI`: Dependency Injection với GetIt và Injectable
- `Routes`: Điều hướng ứng dụng bằng GoRouter

BLoC đảm nhiệm việc quản lý trạng thái và tách biệt giao diện khỏi logic
nghiệp vụ. Repository Pattern giúp phân tách tầng dữ liệu, trong khi
Dependency Injection hỗ trợ quản lý vòng đời các service trong ứng dụng.

### Trách nhiệm thực hiện

- Phân tích yêu cầu và thiết kế luồng ứng dụng
- Thiết kế kiến trúc và cấu trúc thư mục
- Xây dựng giao diện người dùng
- Phát triển chức năng xác thực
- Xây dựng tính năng chat thời gian thực
- Tích hợp Firebase Authentication và Cloud Firestore
- Tích hợp Supabase Storage để lưu trữ hình ảnh
- Xây dựng hệ thống Push Notification và Local Notification
- Phát triển chức năng tìm kiếm bạn bè và tin nhắn
- Xây dựng hệ thống đa ngôn ngữ
- Quản lý trạng thái bằng BLoC
- Thiết lập Dependency Injection
- Xử lý lỗi và tối ưu trải nghiệm người dùng
